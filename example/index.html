hedgehogify

The best way to get hedgehogs to explode all over a website. Click one to spin it.

Cast

Filtering happens when the instance is built, so toggling one rebuilds it.

Install

npm install @nowtwo-llc/hedgehogify

Use

import HedgeHogify from '@nowtwo-llc/hedgehogify';
// or: import { HedgeHogify } from '@nowtwo-llc/hedgehogify';

const hedgehogify = new HedgeHogify();

hedgehogify.burst();              // 50 hedgehogs, cleared after 10s
hedgehogify.burst(8);             // just a few
hedgehogify.konami(() => { ... }); // wire it to the Konami code
HedgeHogify.clear();              // remove them now

Events

  • he:hedgehogify:start — a burst began
  • he:hedgehogify:stop — the hedgehogs cleared

Both are dispatched on document.
